# Papers

Research code portfolio for reproducible empirical projects. Each folder is kept code-only: raw data, generated result tables, figures, notebooks, and manuscript files are intentionally excluded.

## Projects

| Project | Topic |
|---|---|
| [careerbuilder-job-recommendation](careerbuilder-job-recommendation/) | Chronological job-recommendation study comparing profile/content signals with observed application history. |
| [ibm-telco-value-aware-prioritization](ibm-telco-value-aware-prioritization/) | Churn prioritization that compares risk-only ranking with CLTV-aware fixed-capacity ranking. |
| [orange-belgium-uplift-evaluation](orange-belgium-uplift-evaluation/) | Telecom churn-risk and treatment-effect evaluation using randomized campaign data. |
| [resume-ranking-evaluation-audit](resume-ranking-evaluation-audit/) | Funnel-aware audit of resume-job ranking evaluation using random and recruiter-rejection candidate pools. |
| [sme-bankruptcy-generalization](sme-bankruptcy-generalization/) | SME bankruptcy model generalization across future years and industry sectors. |
| [stated-risk-trading-behavior](stated-risk-trading-behavior/) | Out-of-time prediction of retail investor trading after extreme negative-return events. |

## Repository Style

These projects focus on implementation, configuration, and lightweight tests. External datasets should be downloaded separately and generated outputs should stay local.
